# Acheuléen: The Dawn of Human Economy (~400.000 v. Chr.)

Ein biophysikalisches, isometrisches Open-Source-Diorama über die Ursprünge menschlicher Arbeitsteilung, thermodynamischer Abhängigkeit und evolutionärer Ökologie.

> **Philosophie:** Das Spiel ist keine konsumierbare Blackbox. Das Spiel besteht darin, im Dialog mit generativer/agentischer KI an der Simulation mitzuwirken, Kausalitäten zu erforschen und die Menschheitsgeschichte evolutionsgetreu nachzubauen.

---

## 🎮 Schnellstart (Lokal im Browser)

1. Repository klonen:
   ```bash
   git clone https://github.com/gentlemani85/groundsole-game.git
   cd groundsole-game
   ```
2. Lokalen Server starten (ohne Node-Abhängigkeiten, reines Python):
   ```bash
   python3 -m http.server 8080
   ```
3. Öffne im Browser: **`http://localhost:8080`**

---

## 🏛️ Die 4 Verfassungsregeln (CONSTITUTION)

Jeder Mitwirkende (und jeder KI-Agent) muss zwingend die Regeln in [CONSTITUTION.md](CONSTITUTION.md) einhalten:

1. **Biophysikalische Kausalität:** Geschlossene Energie- und Stoffkreisläufe. Keine Zauberei, keine Fantasie-Werte. (Hütte = Wind-/Schlafschutz, Feuer = zwingende Wärmequelle).
2. **Historische & Evolutionäre Kohärenz:** Wir befinden uns im Altpaläolithikum (*Acheuléen*, Faustkeile, kontrolliertes Feuer). Keine Anachronismen.
3. **Dynamische Homöostase:** Jede Änderung muss den automatisierten Simulationstest (`npm test` bzw. `node test/simulate.mjs`) über 1.500 Ticks bestehen. Der Clan darf weder aussterben noch explodieren.
4. **Emergente Komplexität:** Neue Pflanzen, Tiere oder Mechaniken müssen sich in das bestehende Nahrungs-, Dünge- und Beziehungsnetz einfügen.

---

## 🧪 Automatische Test-Verifikation
